!!! tip "先跑起来，再慢慢装饰"
    一套完整的知识库 = **Markdown 文件**（内容）+ **mkdocs.yml**（结构外观）+ **GitHub Actions**（自动构建发布）。
    你只需要持续往 `docs/` 目录里加 `.md` 文件，剩下的交给工具。
