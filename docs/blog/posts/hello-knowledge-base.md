# 用 MkDocs 搭一个会长大的知识库

这是我建站的第一篇文章，用来验证博客插件、标签和部署流水线都工作正常。

<!-- more -->

## 为什么选这套方案

- **内容即文件**：所有笔记都是 `.md`，纯文本，随时能迁走，不被任何平台锁定。
- **零服务器成本**：GitHub Pages 免费托管，配自定义域名和 HTTPS 也免费。
- **改完即上线**：推一次代码，Actions 构建并发布，不需要登录服务器。

## 接下来的计划

1. 把散落在各处的笔记搬进来
2. 给每个分区定一个固定模板
3. 每周固定时间整理一次

!!! quote "记一句话提醒自己"
    知识库的价值不在于「写了多少」，而在于「下次要用时能不能搜到」。
